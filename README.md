# Modal Application - Welcome Modal

This project demonstrates a simple **Modal Application** that greets users with a welcoming message. The modal appears as a centered overlay on a webpage and can be customized as needed.

---

## Features

- **Welcome Message**: Displays a friendly greeting ("Hello Everyone!!! Welcome to my World!") in a modal dialog.
- **Background Overlay**: Dims the background for better focus on the modal.
- **Responsive Design**: Works seamlessly on various screen sizes.
- **Customizable**: Easily change the text, styles, and functionality.

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

---

## Getting Started

### Prerequisites

- A modern web browser.

### Installation

1. Clone this repository:

```bash

   git clone https://github.com/your-username/welcome-modal.git
  
```
  
2. Navigate to the project directory:

```bash

  cd welcome-modal

```

3. Open index.html in a browser to see the modal in action.
